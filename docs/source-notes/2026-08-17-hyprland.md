# Hyprland on Iris Pro (2026-08-17)

## Abstract

With the Intel lid already at `i915drmfb` 2880×1800, Hyprland 0.56.2
is a working seated session on this `MacBookPro11,3` if Aquamarine is
pinned to `/dev/dri/intel-igpu` and forced to **legacy DRM**
(`AQ_NO_ATOMIC=1`). The first session was a three-bind DRM proof. The
session that stayed up the same evening had real binds, waybar, and
Command as Super.

The red overlay that filled the panel was **hyprlang parse errors**,
not a modeset failure. Three 0.56-removed keys were enough to create
it. After they were dropped, `Hyprland --verify-config` reported
`config ok` and `hyprctl reload` cleared the overlay.

Plasma Wayland remains the other proven desktop
([`2026-08-17-plasma-wayland.md`](2026-08-17-plasma-wayland.md)).
Omarchy is the next **port**, not a wipe:
[`docs/graphics/omarchy.md`](../graphics/omarchy.md).

## What worked

- Session: `Type=wayland`, `Desktop=Hyprland`, wrapper
  `retinaforge-hyprland-intel` →
  `Hyprland --config /usr/local/share/retinaforge/hyprland-intel.conf`.
- Connector: eDP-2 2880×1800, scale 2. Aquamarine logged legacy drm
  (`AQ_NO_ATOMIC`). `eglQueryDevicesEXT EGL_BAD_ALLOC` and
  `Cannot commit when a page-flip is awaiting` appeared; the lid still
  painted.
- `hid_apple swap_opt_cmd=0` (live + `/etc/modprobe.d/retinaforge-hid-apple.conf`).
  Input: `kb_layout=nl`, `kb_model=pc105` (not `applealu_iso`+`mac`).
- udev `/dev/dri/intel-igpu` (not `by-path`, colons).

## Config overlay

Hyprland 0.56 still loads hyprlang when the file is not Lua
(`[cfg] Config is NOT lua, loading regular mgr`). Invalid keys:

- `input:touchpad:tap` → `tap-to-click`
- `misc:vfr` → removed (do not set)
- `dwindle:pseudotile` → removed (`preserve_split` kept)

`hyprland-intel.conf` sources `hyprland-retinaforge.conf`, so hardware
errors listed twice.

Verify as the seated user. Root `--verify-config` aborted (SIGABRT)
while the session owned the GPU.

## Not the fix

- Re-enabling `i915.enable_dc`
- Live mux hops (`IGD` / `DIS`)
- Converting the CachyOS daily file to Lua (not required; 0.56 still
  accepts `.conf`). Omarchy 4 **is** Lua — that twin is
  `hyprland-retinaforge.lua`.

## Recreate

[`docs/graphics/hyprland.md`](../graphics/hyprland.md),
[`docs/graphics/omarchy.md`](../graphics/omarchy.md).

```bash
sudo ./scripts/graphics/recreate-desktop.sh hyprland   # CachyOS / SDDM
sudo ./scripts/graphics/recreate-desktop.sh omarchy    # pin only, no SDDM
Hyprland --verify-config --config /usr/local/share/retinaforge/hyprland-intel.conf
```
